Every frame,negotiated.

Khora is a free, open-source game engine written in Rust. Sixty times a second, its parts agree on how to share the frame, so your game keeps its pace on any machine.

Start from zero How it works

Each part of the engine knows several ways to do its job.

Drawing the picture, simulating physics, mixing sound, running your scripts: each is an agent with a few strategies, and it knows what each one costs.

A conductor deals out the frame.

A frame lasts 16.7 milliseconds. The conductor watches frame time, heat and battery. Each agent asks for a share, and the conductor settles what each one gets.

When the machine runs hot, the budget shrinks.

The agents renegotiate. Shadows drop a resolution; a few scripts finish one frame later. The game itself never changes, only the way the engine draws and runs it.

Scripts · Ergon

Twenty lights, one behavior.

Ergon is Khora's language for gameplay. Each firefly here carries the same small behavior, which moves it every frame. If a frame runs out of time, a script pauses at a safe place and picks up there on the next frame, even after you edit its code while the game runs.

behavior Firefly {
    // centre, reach and speed on each axis
    float cx = 0.0;  // … cz, rx … rz, sx … sz
    float t = 0.0;

    void Update(float dt) {
        t += dt;
        this.SetPosition(Vec3(
            cx + rx * Wave(t * sx),
            cy + ry * Wave(t * sy),
            cz + rz * Wave(t * sz)));
    }
}

Physics · Rapier

Forty-five crates. One boulder.

Every crate is a rigid body with its own collider. The boulder is thrown, the tower gives way, and the pieces collide, tumble and come to rest, each step of the simulation run inside the share of the frame that physics was given.

Inside the engine

The parts, and what they do.

Each big part of Khora does one job and knows more than one way to do it. Every row opens the page that explains it from the start.

  • The conductorBudgetsDCC · GORNAWatches frame time, heat, battery and memory, and deals out each frame's budget among the agents.
  • RenderingThe picturerender agent · lanes · wgpuPhysically based light, shadows and sky. When the budget shrinks, it switches to a cheaper way of drawing the frame.
  • PhysicsThings that moverigid bodies · collidersBodies fall, collide and come to rest, stepped forward inside their share of the frame.
  • AudioSound in spacespatial mixingEvery sound is placed where it comes from. When time runs short, the quietest voices drop out before you could hear a glitch.
  • ErgonYour scriptslanguage · VM · hot reloadGameplay code that pauses at a safe point when its time is up, and resumes on the next frame exactly where it stopped.
  • CRPECSYour world's dataentities · componentsEntities stored in pages by what they mean, so each part of the engine reads only what it needs.
  • SavesScenes and progressrecords · game savesScenes are saved as records you can read. A game save keeps only what changed, and a failed load leaves the world exactly as it was.
